# Employee Management System
A full-stack Employee Management System built using **Spring Boot** for the backend and **React with TypeScript** for the frontend.
The application allows users to create, view, and update employee information through a REST API and a responsive web portal.
---
## Features

### Backend

- Create Employee

- Get All Employees

- Update Employee

- Input validation

- Global exception handling

- Employee not found handling

- RESTful API

- H2 in-memory database

- Spring Data JPA

- Layered architecture

### Frontend

- Employee List

- Add Employee

- Edit Employee

- Client-side form validation

- REST API integration using Axios

- React Router navigation

- Responsive user interface

- Material UI components

- Loading and error states

- Success messages

### API Testing

- REST APIs tested using Postman

- Create Employee testing

- Get All Employees testing

- Update Employee testing

- Validation testing

- Employee not found testing
